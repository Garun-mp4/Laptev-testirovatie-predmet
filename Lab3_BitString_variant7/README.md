# Лабораторная работа № 3 — вариант 7

В архиве находятся два проекта, как требуется в методичке:

1. `project1_custom_tests` — собственный базовый класс `Test` и наследник `BitStringTest`.
2. `project2_doctest` — модульные тесты того же класса через официальный `doctest`.

Из этой папки можно собрать оба проекта и запустить оба набора тестов одной командой CTest:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --config Debug
ctest --test-dir build -C Debug --output-on-failure
```

Первое конфигурирование скачивает doctest 2.4.11 с официального GitHub, если он еще не установлен. Поэтому при первой сборке нужен доступ в интернет. Каждый подпроект также можно собрать отдельно по инструкциям в его `README.md`.
