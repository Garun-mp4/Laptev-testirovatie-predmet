# ЛР № 3 — проект 2 (doctest)

Второй проект проверяет тот же рабочий класс с помощью официального фреймворка **doctest 2.4.11**.

При первом запуске CMake автоматически получает doctest из официального GitHub-репозитория, если он не установлен в системе.

## Запуск

```bash
cmake -S . -B build
cmake --build build
./build/lab3_doctest
```

Дополнительно можно запустить тест через CTest:

```bash
ctest --test-dir build --output-on-failure
```

В GitHub Codespaces достаточно открыть папку проекта в терминале и выполнить эти команды.
